# landing-pages-demos

Portfólio de demonstração dos modelos de sites profissionais que podemos criar.

Este repositório é destinado a integrar uma landing page que demonstra os modelos de sites profissionais oferecidos (para venda, etc.).

## Estrutura

- `index.html` + `css/` + `js/` — landing page principal (portfólio)
- `modelos/` — landing pages por nicho, cada uma com sua própria estrutura:
  - `agencia-digital/` — agências e serviços digitais (web, design, marketing)
  - `cursos-online/` — cursos e treinamentos online
  - `saude-estetica/` — saúde, estética e bem-estar
  - `nutricao-esportiva/` — suplementação e nutrição esportiva
  - `bem-estar/` — saúde mental e bem-estar
  - `consultoria-gestao/` — consultoria de gestão para PMEs / MEI
  - `planejamento-financeiro/` — planejamento financeiro e investimentos

Todos os modelos são páginas estáticas (sem e-commerce/backend de venda), ideais
para apresentação de serviços, captação de leads e agendamento.

## Stack

- Frontend: HTML, CSS e JavaScript (estático, sem build)
- Deploy: Vercel
- Backend/Banco: Supabase (a integrar nos formulários)
